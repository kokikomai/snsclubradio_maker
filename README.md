# SNSクラブラジオ 原稿作成ツール

講座の生徒から寄せられた質問を元に、ラジオ番組の原稿を自動生成するCLIツールです。

## 機能

1. **質問の取得** - Googleスプレッドシート（Googleフォームの回答含む）から質問を自動取得
2. **題材の提案** - AIが質問を分析し、ラジオで取り上げる題材を複数提案
3. **題材の選択** - 提案された題材から使用するものを選択
4. **原稿の生成** - 選択した題材に基づいてラジオ原稿を自動生成
5. **原稿の修正** - フィードバックを入力して原稿を修正可能

## セットアップ

### 1. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. 環境変数の設定

`.env.example` をコピーして `.env` を作成し、必要な値を設定してください。

```bash
cp .env.example .env
```

#### 設定項目

| 変数名 | 説明 |
|--------|------|
| `ANTHROPIC_API_KEY` | Anthropic APIキー（[取得はこちら](https://console.anthropic.com/)） |
| `SPREADSHEET_ID` | GoogleスプレッドシートのID（URLの `/d/` と `/edit` の間の部分） |
| `SHEET_NAME` | シート名（デフォルト: `質問`） |
| `QUESTION_COLUMN` | 質問が入っている列（デフォルト: `B`） |
| `OUTPUT_DIR` | 原稿の出力先ディレクトリ（デフォルト: `output`） |

### 3. Google API の設定

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. Google Sheets API を有効化
3. OAuth 2.0 クライアントIDを作成（デスクトップアプリ）
4. `credentials.json` をダウンロードしてプロジェクトルートに配置

初回実行時にブラウザが開き、Googleアカウントでの認証が求められます。

## 使い方

```bash
python main.py
```

### 実行の流れ

1. **質問の取得**: スプレッドシートから質問を読み込み、一覧表示
2. **題材の提案**: 提案数を入力すると、AIが題材を複数提案
3. **題材の選択**: 番号を入力して題材を選択
4. **原稿の生成**: パーソナリティ名、番組名、目安時間を入力して原稿を生成
5. **保存**: 原稿をMarkdownファイルとして保存
6. **修正**: 必要に応じてフィードバックを入力して修正

## 出力例

生成された原稿は `output/` ディレクトリに保存されます。

```
output/
├── script_20250106_120000.md
└── script_final_20250106_121500.md
```

## Googleフォームとの連携

Googleフォームの回答は自動的にスプレッドシートに保存されます。

1. Googleフォームを作成
2. 「回答」タブ → スプレッドシートアイコンをクリック
3. 作成されたスプレッドシートのIDを `.env` に設定
4. 質問が入る列（通常は回答の列）を `QUESTION_COLUMN` に設定
