# SNSクラブラジオ 原稿作成ツール

講座の生徒から寄せられた質問を元に、ラジオ番組の原稿を自動生成するWebアプリです。

## 機能

1. **過去原稿の分析** - 公開済みの原稿を読み込み、扱ったテーマを把握
2. **質問の取得** - Googleスプレッドシート（Googleフォームの回答含む）から質問を自動取得
3. **質問のスコアリング** - AIが質問を分析し、以下の基準でスコアリング
   - 需要スコア: 過去に人気があったテーマとの関連性
   - 新鮮さスコア: まだ扱っていない新しい切り口か
   - 具体性スコア: 具体的で答えやすい質問か
4. **上位質問の自動ピックアップ** - スコア上位10件を自動選出
5. **題材の提案** - AIがピックアップした質問から題材を複数提案
6. **原稿の生成** - 選択した題材に基づいてラジオ原稿を自動生成
7. **原稿の修正** - フィードバックを入力して原稿を修正可能

## セットアップ

### 1. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. 過去の原稿を配置

公開済みの原稿を格納したディレクトリを用意してください。

```bash
# 例: SnsClub-radioリポジトリをクローン
git clone https://github.com/kokikomai/SnsClub-radio.git
```

### 3. 環境変数の設定

`.env.example` をコピーして `.env` を作成し、必要な値を設定してください。

```bash
cp .env.example .env
```

#### 設定項目

| 変数名 | 説明 |
|--------|------|
| `ANTHROPIC_API_KEY` | Anthropic APIキー（[取得はこちら](https://console.anthropic.com/)） |
| `SPREADSHEET_ID` | GoogleスプレッドシートのID（URLの `/d/` と `/edit` の間の部分） |
| `SHEET_NAME` | シート名（デフォルト: `質問`） |
| `QUESTION_COLUMN` | 質問が入っている列（デフォルト: `B`） |
| `OUTPUT_DIR` | 原稿の出力先ディレクトリ（デフォルト: `output`） |
| `SCRIPTS_DIR` | 過去の原稿ディレクトリ（スコアリング用） |
| `TOP_QUESTIONS_COUNT` | スコアリングで選ぶ上位件数（デフォルト: `10`） |

### 4. Google API の設定

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. Google Sheets API を有効化
3. OAuth 2.0 クライアントIDを作成（デスクトップアプリ）
4. `credentials.json` をダウンロードしてプロジェクトルートに配置

初回実行時にブラウザが開き、Googleアカウントでの認証が求められます。

## 使い方

### Webアプリ（推奨）

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動的に開きます。

### CLIツール

```bash
python main.py
```

### 実行の流れ

1. **過去原稿の読み込み**: 公開済みの原稿を読み込み
2. **質問の取得**: スプレッドシートから質問を読み込み
3. **スコアリング**: AIが質問を分析し、上位10件を自動選出
4. **題材の提案**: 提案数を入力すると、AIが題材を複数提案
5. **題材の選択**: 題材を選択
6. **原稿の生成**: パーソナリティ名、番組名、目安時間を入力して原稿を生成
7. **保存/ダウンロード**: 原稿をMarkdownファイルとして保存またはダウンロード
8. **修正**: 必要に応じてフィードバックを入力して修正

## 出力例

生成された原稿は `output/` ディレクトリに保存されます。

```
output/
├── script_20250106_120000.md
└── script_final_20250106_121500.md
```

## Googleフォームとの連携

Googleフォームの回答は自動的にスプレッドシートに保存されます。

1. Googleフォームを作成
2. 「回答」タブ → スプレッドシートアイコンをクリック
3. 作成されたスプレッドシートのIDを `.env` に設定
4. 質問が入る列（通常は回答の列）を `QUESTION_COLUMN` に設定
